# Security reporting

Do not post secrets, real plates, ticket history or account data in public issues. Report a suspected vulnerability through the repository's private GitHub vulnerability-reporting channel if enabled, or contact the maintainer through their GitHub profile to arrange a private report.

Include affected versions, a minimal synthetic reproduction, impact and any proposed fix. The owner API, restricted viewer and background worker have different trust boundaries; please identify the service involved. Never test against other people's garages or the live municipal payment workflow.
