# Contributing

Use an issue to describe a bug or proposed change, with synthetic examples. Do not submit real plates, owners' contact details, ticket records, credentials, database files or screenshots containing them.

Install the development dependencies and run the checks in [the development guide](docs/development.md). Include behavior-focused tests for changed collection/authentication/notification logic. Keep API contracts and configuration docs in sync. Avoid coupling the map-only service to private endpoints. Use env variables for deployment differences and secret files for credentials.
